# 伴梦童话（微信小程序）MVP 产品需求文档

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 产品名称 | 伴梦童话 |
| 产品形态 | 微信小程序 |
| 当前版本 | MVP（最小可行性产品） |
| 产品定位 | 结合 AI 绘本生成与亲子声音克隆的个性化有声绘本产品 |
| 主要使用者 | 家长 |
| 主要受益者 | 2～9 岁儿童 |
| 核心场景 | 睡前陪伴、亲子共共读、日常情绪安抚、成长教育 |

## 2. 产品概述

伴梦童话帮助家长用自己的声音或家庭成员的声音，为孩子定制专属故事。家长可以选择故事模板快速开始，也可以自定义故事主题、教育目标、故事场景和主人公，再补充故事时长等需求。系统将这些需求整理为故事创作提示词，先生成文本故事、封面图和章节插图，家长预览并确认满意后，再生成有声故事并播放。

每个成功生成并完成有声播放的故事都会保存到孩子的“故事日记本”中，家长可以随时播放、收藏、重命名、删除或分享。产品同时提供声音克隆次数、故事生成次数、卡密兑换和邀请奖励，形成“体验—使用—分享—转化”的完整闭环。

## 3. 产品目标

### 3.1 MVP 目标

1. 让家长能够顺利完成微信登录和孩子资料设置。
2. 让家长能够在小程序内录制并克隆一个家庭声音。
3. 让家长能够通过故事模板或完全自定义需求生成一部个性化文本绘本，并在确认后生成有声故事。
4. 让家长能够以沉浸式播放器为孩子播放故事。
5. 让生成的故事自动沉淀为可反复使用的故事资产。
6. 让用户能够通过卡密获得使用权益，并通过邀请新用户获得奖励。

### 3.2 MVP 暂不包含

- 故事过程中的 AI 故事问答。
- 孩子独立注册或独立使用账号。
- 孩子答题、成长测评或学习数据分析。
- 单张插图的重新生成。
- 复杂的故事编辑器。
- 多人实时共读或实时语音通话。

## 4. 目标用户与使用场景

### 4.1 主要用户：家长

家长希望用更有情感温度的方式陪伴孩子，但时间有限，或者希望把自己的声音留给孩子。家长负责登录、设置资料、录制声音、生成故事、管理故事并进行播放。

### 4.2 典型场景

**睡前陪伴**

家长选择睡前主题和较长故事时长，使用自己的声音生成故事并设置睡眠定时，陪孩子进入睡眠。

**情绪安抚**

家长选择情绪安抚类主题和熟悉的生活场景，用亲人的克隆声音播放一段温柔故事。

**习惯培养**

家长选择整理、勇敢、分享、独立等教育目标，生成适合孩子年龄的故事。

**异地陪伴**

家长或家庭成员提前录制声音并生成故事，在无法陪伴孩子时播放专属故事。

## 5. 产品结构

底部导航固定为三个栏目：

1. **首页**：创建故事、故事模板、继续播放、故事日记本和权益入口。
2. **录音室**：录制、克隆和管理家庭声音。
3. **我的**：个人资料、次数权益、邀请奖励、卡密兑换、通知和设置。

辅助页面包括：欢迎/登录、资料完善、定制故事向导、文本故事生成等待、文本故事预览、有声故事生成等待、沉浸播放器、通知中心、故事日记本、兑换激活码、关于伴梦等。

## 6. 核心用户流程

### 6.1 首次使用流程

欢迎页 → 微信登录 → 完善孩子资料 → 查看首页引导 → 进入录音室 → 完成声音克隆 → 选择故事模板或自定义创作 → 生成故事创作提示词 → 生成文本故事 → 预览文本故事 → 确认满意 → 生成有声故事 → 播放 → 自动保存到故事日记本。

### 6.2 老用户生成故事流程

首页 → 创建故事 → 选择故事模板或自定义创作 → 选择或填写主题、教育目标、场景、主人公和时长 → 生成故事创作提示词 → 选择声音模式 → 确认生成 → 等待生成文本故事 → 预览文本故事 → 确认满意 → 生成有声故事 → 开始播放 → 保存到故事日记本。

### 6.3 卡密兑换流程

我的 → 兑换激活码 → 输入卡密 → 查看权益说明 → 确认兑换 → 兑换成功 → 次数或会员权益到账。

### 6.4 邀请裂变流程

我的 → 邀请好友 → 分享专属邀请码或邀请卡片 → 新用户完成微信登录并绑定邀请码 → 新用户首次成功生成故事 → 邀请双方获得奖励 → 通知中心展示奖励结果。

## 7.1 AI能力与模型配置

伴梦童话的文本、图片、声音克隆和语音合成能力统一使用 StepFun。以下配置用于产品、运营和后续上线验收对齐：

| AI能力 | 使用的 StepFun 能力 | 产品用途 | 产出结果 |
|---|---|---|---|
| 提示词优化 / 故事生成 | `step-3.7-flash` | 根据孩子资料、故事主题、教育目标、场景、主人公、时长和家长补充要求，整理故事创作提示词并生成完整文本故事 | 故事需求摘要、创作提示词、章节文本 |
| 封面生成 | `step-image-edit-2` | 根据故事主题、主人公和整体画面风格自动生成故事封面 | 故事封面图 |
| 章节画面生成 | `step-image-edit-2` | 根据故事章节内容生成风格统一的绘本画面 | 章节插图 |
| 声音克隆 | `/step_plan/v1/audio/voices` | 将家长或获得授权的家庭成员录音创建为可管理的专属声音 | 克隆声音及声音状态 |
| TTS有声合成 | `stepaudio-2.5-tts` | 将确认后的故事文本，按照选定的声音模式合成为故事旁白 | 旁白音频、章节旁白音频和生成状态 |
| 固定白噪音 | Cloud Storage 白噪音库 | 为故事旁白提供简单、稳定的睡眠和陪伴背景声 | 白噪音文件和白噪音元数据 |
| 音频混音 | CloudBase 后端 FFmpeg（按需） | 用户选择白噪音时，将旁白与固定白噪音混合为最终可播放音频 | 最终故事音频、章节音频和播放状态 |

### AI能力使用规则

- 所有 AI 生成内容都要结合孩子年龄、兴趣和家长确认的故事需求。
- AI 生成前展示故事需求摘要，帮助家长确认系统理解是否准确。
- 文本故事、封面图和章节插图作为同一部故事统一生成和保存。
- 家长确认文本故事满意后，才进入 TTS 有声合成流程。
- AI 生成失败时需要明确展示失败状态；失败任务不应误扣故事次数或声音克隆次数。
- AI 生成内容需要经过儿童内容安全检查，异常内容进入后台审核。

### 音频合成与等待体验

- StepFun 的 TTS 仅负责生成旁白，不负责生成或混入背景音；背景音采用产品预置的固定白噪音库，不在每次生成时调用 AI 生成。
- 背景白噪音为可选能力，默认选项为“关闭背景音”。MVP 只提供少量固定白噪音选项，例如柔和白噪音、雨声、海浪声和风声；不做复杂的音乐推荐、自动配乐或用户上传背景音。
- 固定白噪音文件由产品统一维护并上传到 Cloud Storage，文件应使用自有或已获得合法授权的素材。
- 小程序前端不得直接调用 StepFun，也不得在用户设备上运行 FFmpeg。StepFun 密钥、音频下载、混音和最终文件上传统一放在 CloudBase 后端处理。
- 有声故事采用异步任务模式：小程序提交生成请求后立即获得 `jobId`，不阻塞等待 StepFun、音频下载和混音全部完成。
- 任务由 CloudBase 云函数负责创建和编排。用户关闭背景音时，旁白生成完成后直接将旁白文件作为可播放音频返回，不读取白噪音、不执行 FFmpeg 混音；用户选择白噪音时，才读取白噪音并执行按需混音。音频处理较重或并发较高时，允许使用 CloudBase 云托管承载混音 worker。
- 音频任务至少记录以下状态：`queued`（排队中）、`tts_generating`（生成旁白）、`mixing`（加入白噪音，仅选择白噪音时出现）、`ready`（可播放）、`failed`（失败）。前端展示真实阶段，不使用虚假的固定进度。
- 音频任务完成后将最终音频的 `fileID`、时长、章节音频信息和完成时间写入故事记录；用户可以离开等待页，返回后从故事日记本或通知中心继续播放。
- 固定白噪音优先使用已上传和已缓存的素材；用户选择白噪音时，白噪音按故事时长循环，并在开头和结尾进行短淡入淡出，避免突然开始或结束。
- 默认白噪音音量应明显低于旁白，不能影响儿童听清故事；用户可以在生成前选择白噪音类型或关闭背景音。
- 相同故事文本、声音、白噪音类型和音频参数组合可以复用已生成结果，避免重复调用 TTS 和混音。
- 用户关闭背景音时跳过 FFmpeg，直接使用旁白文件，缩短等待时间并降低云函数资源消耗；执行混音时仍需清理云函数临时目录，所有中间文件处理完成后删除。

### 提示词敏感词控制

- 家长填写主题、教育目标、场景、主人公和补充要求时，产品需要进行敏感词和儿童内容风险检查。
- 系统整理故事创作提示词后，在展示故事需求摘要和开始生成前再次检查，避免用户输入在整理过程中产生新的风险表达。
- 对正常内容不打扰用户；对疑似风险内容提示家长修改，并给出适合儿童故事的替换建议。
- 对明确不适合儿童的内容直接拦截，不进入故事生成、图片生成或 TTS 流程。
- 前台不展示具体敏感词原文，只提示风险类型，例如“包含不适合儿童的暴力、色情、违法、仇恨、危险行为或隐私内容”。
- 敏感词拦截或修改过程中不扣除故事次数，不消耗声音克隆权益。
- 家长修改后可以重新检查；只有检查通过后，才允许确认生成。
- 命中风险的提示词需要记录风险类别、处理结果和时间，供后台内容安全人员复核。

## 8. 页面功能说明

### 8.1 欢迎 / 登录页

#### 页面目标

让家长快速理解产品价值并完成进入。

#### 页面内容

- 品牌名称“伴梦童话”。
- 产品宣传语，例如“让爱，留在每一个睡前故事里”。
- 简短说明：用熟悉的声音，为孩子生成专属故事。
- 微信一键登录按钮。
- 用户协议和隐私政策入口。

#### 功能要求

- 首次登录后进入资料完善页。
- 已完成资料的用户直接进入首页。
- 用户未同意相关协议时，不进入正式使用流程。

### 8.2 资料完善页

#### 页面目标

建立孩子的基础画像，为故事内容提供个性化依据。

#### 信息项

- 孩子昵称。
- 年龄。
- 性别。
- 兴趣偏好。
- 家长称呼。
- 常用播放时间或睡前时间。

#### 功能要求

- 支持首次填写和后续修改。
- 年龄为必填项，其他信息可根据业务策略设置为必填或选填。
- 完成后进入首页。
- 页面需要说明资料将用于生成更适合孩子的故事。

### 8.3 首页

#### 页面目标

让家长一进入小程序就能创建故事、继续播放或管理已有故事。

#### 页面模块

1. **欢迎区域**：显示家长称呼或孩子昵称。
2. **权益区域**：显示剩余故事生成次数、免费克隆次数或会员状态。
3. **创建故事主入口**：突出展示“为孩子生成一个故事”。
4. **故事模板区域**：展示适合当前年龄段的模板，支持一键套用后修改。
5. **继续播放**：展示最近播放的故事，支持一键继续。
6. **故事日记本入口**：进入全部已生成故事。
7. **邀请有礼入口**：展示当前可获得的邀请奖励。
8. **推荐故事区域**：可展示适合当前年龄段的故事主题。

#### 空状态

- 没有声音时：提示先去录音室创建专属声音。
- 没有故事时：提示创建第一部故事。
- 次数不足时：引导兑换卡密或邀请好友。

### 8.4 录音室

#### 页面目标

让家长能够录制、克隆和管理家庭声音。

#### 页面模块

- 声音列表（**支持删除所有保存的声音**）。
- 新建声音按钮。
- 声音名称，例如“妈妈的声音”“爸爸的声音”。
- 声音试听按钮。
- 声音使用说明和授权提示。
- 免费克隆次数、剩余克隆权益提示。

#### 新建声音流程

录音说明 → 开始录音 → 完成录音 → 试听 → 填写声音名称 → 确认克隆 → 克隆完成 → 保存到声音列表。

#### 功能要求

- 每次只能录制和克隆一个声音源。
- 录音过程中支持暂停、继续和重新录制。
- 克隆前必须确认声音来源已经获得本人同意。
- 支持家长管理多个已保存的家庭声音，以便使用不同声音模式。
- 支持试听、重命名和删除已保存的声音。
- 声音克隆失败时应明确提示原因和后续操作。

声音克隆能力使用 StepFun 的 `/step_plan/v1/audio/voices`，克隆完成后将声音保存到当前家长账号的声音列表中。

### 8.5 定制故事向导

#### 页面目标

通过故事模板或自定义需求完成故事创作，降低家长输入成本，同时保留足够的个性化空间。

#### 创建方式

**方式一：使用故事模板**

- 展示适合不同年龄和场景的故事模板。
- 模板可以包含默认的主题、教育目标、场景、主人公设定和故事时长。
- 家长可以直接套用模板。
- 家长可以修改模板中的任意内容。
- 修改后的内容以家长最终确认的内容为准。

**方式二：自定义创作**

- 家长自行填写或选择主题。
- 家长自行填写或选择教育目标。
- 家长自行填写或选择故事场景。
- 家长自行填写或选择主人公。
- 家长选择故事时长。

#### 创建步骤

**第一步：选择故事模板或开始自定义**

- 选择故事模板快速开始。
- 选择“自定义创作”从空白需求开始。

**第二步：选择故事主题**

- 睡前安抚。
- 勇敢与自信。
- 分享与友爱。
- 习惯养成。
- 亲情陪伴。
- 冒险幻想。
- 自定义主题。

主题必须支持家长自定义填写，模板中的主题也可以修改。

**第三步：选择教育目标**

- 情绪管理。
- 独立自主。
- 勇敢表达。
- 礼貌沟通。
- 认识自然。
- 亲子关系。
- 自定义教育目标。

教育目标必须支持家长自定义填写，模板中的教育目标也可以修改。

**第四步：选择故事场景**

- 家庭生活。
- 森林。
- 海洋。
- 太空。
- 城堡。
- 学校或幼儿园。
- 自定义场景。

故事场景必须支持家长自定义填写，模板中的场景也可以修改。

**第五步：设置主人公**

- 选择或填写主人公姓名。
- 选择或填写主人公身份或角色类型。
- 选择或填写主人公性格特点。
- 支持设置多个主人公。
- 支持完全自定义主人公描述。
- 模板中的主人公可以修改或替换。

**第六步：选择故事时长**

- 短篇。
- 中篇。
- 长篇。

故事时长的具体范围由运营人员后续配置，但页面应提前告知预计播放时长。

**第七步：整理故事创作提示词**

系统将家长最终确认的主题、教育目标、场景、主人公、故事时长、孩子资料和其他补充需求，整理为本次故事的创作提示词。

整理前和整理后都需要进行提示词敏感词检查。检查未通过时，页面停止生成并引导家长修改相关内容。

页面需要展示一份易读的“故事需求摘要”，让家长确认系统理解的内容是否准确。摘要至少包含：

- 故事主题。
- 教育目标。
- 故事场景。
- 主人公设定。
- 故事时长。
- 适合的孩子年龄。
- 家长补充的其他要求。

家长确认后，开始生成文本故事。MVP 不要求家长直接编辑复杂的提示词，但应允许返回上一步修改原始需求。

本步骤使用 `step-3.7-flash` 完成需求理解、提示词优化和文本故事生成。

**第八步：选择声音模式**

- 单一克隆声音讲完整故事。
- 不同角色使用不同声音。
- 家长声音作为旁白，AI 声音作为角色声音。

首次使用默认选择“单一克隆声音讲完整故事”。

**第九步：选择声音**

- 展示已保存声音列表。
- 支持试听。
- 未创建声音时，引导前往录音室。
- **无默认官方声音提供。如果用户没有克隆保存任何家庭声音，系统将阻止继续生成，并提示用户立即前往录音室。**

#### 功能要求

- 支持返回上一步修改选择。
- 支持从模板快速开始，也支持完全自定义。
- 主题、教育目标、场景和主人公均支持自定义。
- 生成前展示完整的故事需求摘要和故事创作提示词说明。
- 生成前展示提示词安全检查结果；检查通过显示“适合儿童故事生成”，检查未通过显示风险提示 and 修改入口。
- 生成前明确提示本次将消耗的故事次数。
- 生成前检查是否有可用声音和可用权益。

### 8.6 文本故事生成等待页

#### 页面目标

让家长了解文本故事和绘本画面正在生成，降低等待焦虑。

#### 页面内容

- 当前生成状态：文本故事生成中。
- 故事标题或主题。
- 预计等待提示。
- 生成阶段提示，例如“正在构思故事”“正在组织章节”“正在绘制封面和插图”。
- 生成完成后自动进入文本故事预览页。

文本故事使用 `step-3.7-flash` 生成；封面和章节插图使用 `step-image-edit-2` 生成。

#### 功能要求

- 用户可以离开页面，完成后通过通知中心查看结果。
- 生成失败时明确告知失败原因和处理方式。
- 文本故事完成后先进入预览，不直接进入故事日记本。

### 8.7 文本故事预览页

#### 页面目标

让家长先阅读和查看文本绘本，确认内容满意后，再生成有声故事。

#### 页面内容

- 自动生成的故事封面图。
- 故事标题。
- 故事摘要。
- 故事正文。
- 章节目录。
- 每章插图。
- 预计播放时长。
- 当前选择的声音名称和声音模式。
- “满意，生成有声故事”按钮。
- “重新生成故事”按钮。

#### 功能要求

- 故事封面图自动生成。
- 章节插图根据故事章节自动生成。
- 封面和章节插图统一使用 `step-image-edit-2` 生成，保持同一部故事的画面风格一致。
- 不提供单张图片重新生成入口。
- 家长可以先查看文本和插图，再决定是否生成有声版本。
- 每一部故事首次重新生成免费一次。
- 首次免费重新生成后仍不满意，再次重新生成需要扣除 1 次故事生成额度。
- 重新生成会重新生成该故事的文本、封面图和章节插图，不提供单张图片单独重生成。
- 文本故事预览满意后，进入有声故事生成等待页。
- 文本故事预览阶段的内容不直接计入故事日记本，完成有声故事生成并播放后再正式保存。

### 8.8 有声故事生成等待页

#### 页面目标

让家长了解文本故事正在转化为有声故事，并等待声音生成完成。

#### 页面内容

- 故事标题。
- 当前声音名称 and 声音模式。
- 背景音选择：关闭、柔和白噪音、雨声、海浪声、风声等固定选项。
- 当前生成状态。
- 生成阶段提示，例如“正在准备旁白”“正在生成故事旁白”“正在加入白噪音”“正在整理播放内容”。
- 生成任务状态和必要的失败原因；状态包括排队中、生成旁白、加入白噪音、已完成和失败。
- 生成完成后进入沉浸式播放器。

有声故事使用 `stepaudio-2.5-tts` 合成；声音来源使用家长在录音室完成的 StepFun 声音克隆结果。
StepFun 生成旁白后，用户关闭背景音时直接播放旁白文件；用户选择白噪音时，CloudBase 后端从固定白噪音库读取对应素材，并使用 FFmpeg 混音生成最终故事音频。小程序根据任务结果播放对应文件。

#### 功能要求

- 有声故事生成不会再次收取故事生成额度，故事额度在文本故事生成时计算。
- 有声故事生成失败时明确告知原因，并允许在不重复扣除故事额度的情况下重试。
- 用户可以离开页面，生成任务继续在 CloudBase 后台执行，完成后通过通知中心或故事日记本查看结果。
- 生成请求提交后应立即进入任务状态页，不要求用户持续停留或等待云函数同步返回最终音频。
- 用户重复点击生成时应复用当前未完成任务，避免重复调用 StepFun 和重复混音。

### 8.9 沉浸式播放器

#### 页面目标

为家长给孩子播放故事提供安静、连续、易操作的体验。

#### 页面内容

- 当前章节插图。
- 故事文字或字幕。
- 当前播放章节和整体进度。
- 声音名称。
- 播放、暂停、上一章、下一章。
- 章节目录。
- 播放速度。
- 睡眠定时器。
- 收藏、分享和返回故事日记本。

#### 功能要求

- 播放过程中可切换章节。
- 支持从上次播放位置继续。
- 重复播放已经生成的故事不额外消耗故事次数。
- 播放数据主要服务于家长查看，不建立儿童独立行为账号。
- 睡眠定时结束后停止播放，并保留下次继续播放位置。

### 8.10 故事日记本

#### 页面目标

长期保存孩子的专属故事，形成可回顾的亲子陪伴记录。

#### 页面内容

- 故事封面。
- 故事标题。
- 创建时间。
- 最近播放时间。
- 故事主题标签。
- 收藏状态。
- 播放进度。

#### 功能要求

- 查看故事详情。
- 再次播放。
- 收藏和取消收藏。
- 修改故事名称。
- 删除故事。
- 分享故事。
- 按时间、主题或收藏状态筛选。
- 删除前二次确认，避免误删。

### 8.11 通知中心

#### 页面目标

集中展示与用户权益和故事生成有关的重要消息。

#### 通知类型

- 故事生成完成。
- 故事生成失败。
- 声音克隆完成。
- 声音克隆失败。
- 卡密兑换成功或失败。
- 邀请奖励到账。
- 次数即将用尽。
- 会员即将到期。
- 产品更新和重要提醒。

#### 功能要求

- 未读消息显示未读标识。
- 支持全部标记为已读。
- 重要权益消息保留可查询记录。

### 8.12 我的

#### 页面模块

- 家长账号信息（微信头像与昵称，支持退出微信登录/重新登录）。
- 孩子资料管理。
- 当前故事次数。
- 免费克隆次数和已使用次数。
- 会员状态和有效期。
- 兑换激活码。
- 邀请好友。
- 我的声音（管理与删除已克隆声音）。
- 我的故事日记本。
- 通知中心。
- 隐私、授权与关于伴梦。

### 8.13 兑换激活码

#### 页面目标

支持家长兑换购买或获得的次数卡、会员卡。

#### 功能要求

- 输入卡密。
- 显示卡密对应权益说明。
- 确认兑换。
- 展示兑换结果。
- 展示历史兑换记录。
- 对无效、过期、已使用卡密给出明确提示。
- 兑换后的次数或会员权益立即更新。

#### 卡密类型

1. **次数卡**：增加可生成故事或使用声音克隆的次数。
2. **会员卡**：在指定有效期内获得运营人员配置的会员权益。

卡片面额、可用次数、有效期、奖励内容和会员权益均由运营人员配置。

### 8.14 邀请好友

#### 页面目标

通过专属邀请码和分享卡片促进用户自然裂变。

#### 页面内容

- 用户专属邀请码。
- 邀请分享按钮。
- 邀请规则说明。
- 已邀请人数。
- 待到账奖励。
- 已到账奖励。
- 奖励明细。

#### 奖励规则

- 每个用户拥有专属邀请码。
- 新用户只能绑定一个邀请码。
- 新老用户双方均可获得奖励。
- 奖励在新用户首次成功生成故事后发放。
- 奖励类型和奖励数量由运营人员配置。
- 同一用户不能通过自己的邀请码获得奖励。
- 每次有效邀请只产生一次奖励。

## 9. 声音克隆与删除规则

### 9.1 声音权益与删除

- **无默认官方声音提供。伴梦童话完全基于100%个性化的亲子录制克隆，家长必须自行或邀请家人录音生成。**
- 每个账户前 5 次声音克隆免费。超过 5 次后，每次消耗 1 次可用克隆额度。
- 每次克隆只对应一个声音源。
- **允许删除所有已保存的家庭声音。家长可在“我的家庭声音”列表中，对任意不想要的声音点击删除按钮直接将其清除。**
- 已成功保存的声音可以重复用于生成故事，重复使用声音不再次扣除克隆次数。

### 9.2 声音授权

- 录制者可以是家长本人，也可以是其他家庭成员。
- 克隆其他家庭成员的声音前，家长必须确认已获得本人同意。
- 产品需要在录音前、克隆确认前展示授权提醒。
- 用户可以查看、重命名和删除已保存声音。
- 删除声音前进行二次确认，并说明删除后可能影响使用该声音生成的后续故事。
- 声音克隆成功后，后续故事播放使用该声音进行 TTS 合成，不重复扣除声音克隆次数。

## 10. 故事生成规则

### 10.1 生成内容

每次生成一个完整文本故事，包含：

- 故事标题。
- 故事正文。
- 故事封面图。
- 按章节生成的插图。
- 章节结构。

家长确认文本故事满意后，再生成对应的有声故事，包含：

- 故事正文的声音播放内容。
- 章节播放结构。
- 选定的声音模式和声音组合。
- 选定的白噪音类型及其素材版本标识；关闭背景音时记录为 `none`。
- 旁白音频、混音后的最终音频、音频时长和 Cloud Storage `fileID`。

### 10.2 生成消耗

- 每生成一部文本故事消耗 1 次故事生成额度。
- 文本故事确认满意后生成对应有声故事，不重复消耗故事生成额度。
- 每一部文本故事首次重新生成免费一次。
- 首次免费重新生成后仍不满意，再次重新生成消耗 1 次故事生成额度。
- 重新生成的文本故事会同步重新生成封面图和章节插图。
- 有声故事生成成功并开始播放后，完整故事自动保存到故事日记本。
- 播放、暂停、重复播放、收藏和分享已生成故事不额外消耗次数。
- 文本故事首次生成、需要扣除额度的重新生成，都必须在开始前展示本次消耗，并在用户确认后开始生成。

### 10.3 两阶段生成体验

1. 家长选择故事模板，或进入自定义创作。
2. 家长确认主题、教育目标、场景、主人公、时长和其他补充需求。
3. 产品根据用户需求整理故事创作提示词，并展示故事需求摘要。
4. 家长确认需求摘要后，产品生成文本故事、封面图和章节插图。
5. 家长阅读文本故事并查看绘本画面。
6. 如果不满意，可以使用一次免费重新生成机会。
7. 如果再次重新生成，需要扣除 1 次故事生成额度。
8. 家长确认满意后，产品根据已确认的文本故事和声音模式生成有声故事。
9. 有声故事生成完成后进入播放器，播放后自动保存到故事日记本。

### 10.4 内容体验要求

- 内容适合 2～9 岁儿童理解和收听。
- 根据孩子年龄、兴趣和家长选择生成内容。
- 故事应体现家长选择的教育目标。
- 故事主题、教育目标、场景和主人公均可以来自模板，也可以由家长自定义。
- 模板只提供创作起点，不能限制家长对故事需求的修改。
- 生成故事前，产品需要基于家长最终确认的需求形成统一的故事创作提示词。
- 生成故事前必须完成提示词敏感词检查，确保主题、角色、情节和补充要求适合 2～9 岁儿童。
- 对疑似风险内容优先给出温和的儿童友好改写建议，不直接替家长改变原始意图。
- 对明确违规或不适合儿童的内容直接阻止生成，并提供返回修改入口。
- 故事场景、角色和画面风格保持一致。
- 封面和章节插图应围绕同一故事主题生成。
- 故事问答不属于 MVP，后续版本再加入。

## 11. 次数、会员与卡密规则

### 11.1 权益展示

家长可以在首页和“我的”中看到：

- 剩余故事生成次数。
- 免费声音克隆次数及已使用次数。
- 购买或兑换获得的可用次数。
- 会员名称。
- 会员有效期。
- 会员包含的具体权益。

### 11.2 扣除顺序

建议按照“免费权益优先、已购买权益其次、即将到期权益优先使用”的规则扣除，并在扣除前展示扣除来源。

### 11.3 次数不足

当用户没有足够权益时：

- 不进入生成流程。
- 明确提示当前缺少哪一种权益。
- 提供“兑换激活码”和“邀请好友”两个入口。
- 不影响用户查看、播放、收藏已有故事。

## 12. 家长资料与故事关系

- 一个微信账号对应一个家长账户。
- 一个家长账户可以维护孩子资料。
- 故事默认关联当前孩子资料。
- 家长可以修改孩子资料，但不影响已经生成并保存的故事。
- 资料修改后，仅影响后续生成的故事。
- MVP 以家长给孩子播放为主要行为，不要求孩子独立登录。

## 13. 隐私、授权与安全体验

- 登录时展示用户协议和隐私政策。
- 录音前清晰说明录音用途和声音克隆用途。
- 克隆家庭成员声音时要求确认已经获得本人授权。
- 家长可以删除自己录制的声音（所有声音均支持删除）。
- 家长可以删除生成的故事和故事日记记录。
- 不公开展示用户的原始录音、家庭成员身份或孩子敏感资料。
- 分享时默认分享故事卡片或邀请卡片，不直接公开私人录音。
- 对不适合儿童的故事主题和内容进行限制与提示。

## 14. 异常场景

| 场景 | 产品处理 |
|---|---|
| 未创建声音就创建故事 | 引导进入录音室完成声音克隆 |
| 录音中断 | 保留当前状态，允许继续或重新录制 |
| 声音克隆失败 | 提示重新录制或稍后重试，失败不应误扣权益 |
| 文本故事生成失败 | 提示失败原因和重试入口，失败不应误扣权益 |
| 有声故事生成失败 | 提示失败原因并允许重试，不重复扣除故事生成额度 |
| 有声故事混音失败 | 保留旁白生成结果，提示稍后重试，不重复调用成功的 TTS 任务 |
| 提示词命中疑似风险内容 | 暂停生成，提示风险类型并给出儿童友好修改建议，不扣除权益 |
| 提示词命中明确敏感内容 | 直接阻止生成，不进入图片或 TTS 流程，不扣除权益，并提供返回修改入口 |
| 生成后的故事或图片命中内容风险 | 不展示、不播放、不保存，进入后台内容安全复核，并向家长展示处理状态 |
| 文本故事不满意 | 每部故事首次重新生成免费，之后重新生成扣除 1 次故事生成额度 |
| 生成过程中离开页面 | 生成继续进行，完成后通过通知中心提醒 |
| 用户重复提交有声生成 | 返回已有未完成任务，不重复创建音频任务或扣除权益 |
| 有声任务处理超时 | 任务标记为可重试，保留失败阶段和原因，允许后台或用户重试 |
| 次数不足 | 阻止生成，并引导兑换卡密或邀请好友 |
| 卡密无效 | 提示卡密不存在、过期或已使用 |
| 邀请码已绑定其他用户 | 提示无法重复绑定，并保留原绑定关系 |
| 网络或播放中断 | 支持重新加载和从上次位置继续 |
| 删除故事 | 二次确认，删除后不再出现在故事日记本 |
| 删除声音 | 二次确认，所有已保存声音皆可删除 |

## 15. MVP 验收标准

### 15.1 新用户能够完成

- 微信登录（支持头像、昵称选取与修改）。
- 孩子资料填写。
- 录制并成功保存一个声音。
- 从故事模板开始创建，或进入自定义创作。
- 自定义主题、教育目标、场景和主人公。
- 确认故事需求摘要后生成故事创作提示词。
- 输入包含风险内容时，能够看到提示词安全提示、修改建议或拦截结果。
- 只有提示词安全检查通过后，才可以开始生成并扣除对应权益。
- **声音选择必须由用户亲自克隆（不提供默认声音），无克隆声音无法生成。**
- 查看文本故事、封面和章节插图。
- 使用一次免费重新生成机会。
- 确认文本故事满意后生成有声故事。
- 查看封面、章节插图和故事内容。
- 播放完整故事。
- 在故事日记本中找到并再次播放该故事。

### 15.2 老用户能够完成

- 使用已有克隆声音再次生成故事。
- 在三种声音模式中进行选择。
- 重新生成不满意的文本故事，并正确区分免费次数和额度消耗。
- 管理声音和故事。
- **删除任意已保存克隆声音。**
- 兑换次数卡或会员卡。
- 查看权益变化和兑换记录。
- 分享邀请码并查看奖励状态。

### 15.3 关键体验结果

- 用户能够明确知道当前剩余权益。
- 用户能够明确知道一次操作会消耗什么。
- 生成完成的故事不会因为离开页面而丢失。
- 已生成故事可以反复播放。
- 声音授权、隐私和删除入口清晰可见。
